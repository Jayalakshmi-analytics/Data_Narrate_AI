# Data Narrate AI

### AI-Powered Data Analysis and Data Cleaning Assistant

Data Narrate AI is a web-based application that helps users understand, analyze, and clean datasets using Python and Artificial Intelligence.

## Features

- Upload CSV and Excel datasets.
- Automatic data quality analysis.
- Missing value and duplicate detection.
- Interactive data visualization.
- AI-generated insights in simple English.
- Data Cleaning Studio.
- Missing value handling using Mean, Median, and Mode.
- Preview and download cleaned datasets in CSV and Excel formats.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Gradio
- Google Gemini API
- Google Colab

## How It Works

1. Upload a dataset.
2. Analyze its data quality.
3. View charts and AI-generated insights.
4. Select a column and cleaning method.
5. Preview and download the cleaned dataset.
